# Bevean para desktop

Instaladores do aplicativo de desktop da [Bevean](https://bevean.com) para macOS, Windows e Linux. O app abre direto no seu atendimento, avisa quando o cliente escreve e mostra no ícone quantas conversas estão esperando.

Este repositório guarda **só os instaladores**. Não há código aqui.

## Baixar a versão mais nova

| Sistema | Arquivo |
| --- | --- |
| macOS 10.15+ (Apple Silicon e Intel) | [Bevean-macOS.dmg](https://github.com/Bevean/bevean-desktop/releases/latest/download/Bevean-macOS.dmg) |
| Windows 10 e 11 (64 bits) | [Bevean-Windows-setup.exe](https://github.com/Bevean/bevean-desktop/releases/latest/download/Bevean-Windows-setup.exe) |
| Windows, para a equipe de TI | [Bevean-Windows.msi](https://github.com/Bevean/bevean-desktop/releases/latest/download/Bevean-Windows.msi) |
| Linux, qualquer distribuição | [Bevean-Linux.AppImage](https://github.com/Bevean/bevean-desktop/releases/latest/download/Bevean-Linux.AppImage) |
| Ubuntu, Debian e Mint | [Bevean-Linux.deb](https://github.com/Bevean/bevean-desktop/releases/latest/download/Bevean-Linux.deb) |
| Fedora e openSUSE | [Bevean-Linux.rpm](https://github.com/Bevean/bevean-desktop/releases/latest/download/Bevean-Linux.rpm) |

Todas as versões ficam em [Releases](https://github.com/Bevean/bevean-desktop/releases).

## Na primeira vez que abrir

- **Mac:** o macOS avisa que não consegue verificar o app. Abra **Ajustes do Sistema → Privacidade e Segurança**, role até o aviso do Bevean e clique em **Abrir Mesmo Assim**.
- **Windows:** se aparecer "O Windows protegeu o computador", clique em **Mais informações** e depois em **Executar assim mesmo**.

Depois disso, o app abre normalmente. Entre com o mesmo e-mail e senha da Bevean.
